# Onboarding Feature

## Бизнес-логика

Текущий статус: `Готово частично`.

Onboarding - первый пользовательский flow. Он запускается при команде `/start`, если пользователь еще не прошел все шаги.

Текущие шаги:

- `welcome` - отправляет приветственное сообщение `Привет`.
- `choose_language` - предлагает выбрать базовый язык пользователя кнопками.
- После выбора языка бот сохраняет язык, завершает onboarding и отправляет короткое подтверждение `Готово, язык сохранен.`

## Технические особенности

- Состояние flow хранится в таблице `user_flows`.
- Завершение onboarding дополнительно фиксируется в `users.onboarding_completed_at`.
- Язык пользователя сохраняется в `users.base_language`.
- Кнопка `Еще` переключает страницы языков.
- Пока используется временный набор языков. Финальный список нужно согласовать отдельно.
- При добавлении новых шагов нужно обновлять этот документ и тесты.

## Аналитика

При подключении Amplitude для этой фичи стоит рассмотреть события:

- `onboarding_started` - анализ конверсии пользователей из `/start` в onboarding.
- `onboarding_language_page_viewed` - анализ востребованности страниц выбора языка.
- `onboarding_language_selected` - анализ распределения базовых языков.
- `onboarding_completed` - анализ завершения onboarding.
