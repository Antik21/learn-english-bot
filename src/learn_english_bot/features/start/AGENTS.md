# Start Feature

## Бизнес-логика

Фича отвечает за входную команду `/start`.

Текущий статус: `Готово частично`.

Сейчас бот обрабатывает команду `/start`, создает или находит пользователя и проверяет статус onboarding.

Если onboarding не завершен, управление передается onboarding flow. Если onboarding завершен, бот отправляет короткий ответ `Привет`.

## Технические особенности

- Telegram router находится в `router.py`.
- Текст ответа для пользователя с завершенным onboarding вынесен в `service.py`, чтобы бизнес-ответ можно было тестировать без Telegram API.
- При расширении стартового сценария нужно не раздувать handler, а переносить правила в сервисы и покрывать их тестами.
- Если появятся варианты приветствия, онбординга, выбора языка или выбора тем, перед реализацией нужно уточнить бизнес-сценарий у пользователя.
