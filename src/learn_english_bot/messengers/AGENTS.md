# Messenger Contracts

## Назначение

Папка содержит общий контракт взаимодействия между бизнес-логикой бота и клиентами мессенджеров.

Текущий статус: `Готово частично`.

## Правила

- Бизнес-логика должна работать с `MessengerContext` и возвращать `MessengerAction`.
- Контракт расширяется только под реальные потребности текущих фич.
- В этом слое нельзя импортировать SDK конкретных мессенджеров.
- Адаптеры конкретных мессенджеров должны жить в отдельных подпапках.
